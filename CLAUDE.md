# CLAUDE.md

A Brazilian Portuguese course (A1 to B2) for English speakers. A Rust workspace: `shared` (course model, validation, practice and review logic), `tools/course_builder` (validate, compile, synthesize audio) and `web` (Leptos, server render plus client hydration, run with `cargo leptos watch`).

## Conventions

Follow `docs/conventions/` (type naming, log format, conditional compilation) and the owner's global `~/.claude/CLAUDE.md`. Scripts in `scripts/` wrap the tools; use them.

## Course data

- Author units to the format in `docs/authoring.md`, then run `cargo run --package course_builder -- validate <unit-id>`. The validator is the authority on structure; `shared/tests/course_data.rs` fails `cargo test` if any unit is invalid.
- Every `pt` string is spoken by text-to-speech, so it must be plain speakable text.
- Brazilian Portuguese only. European forms in `pt` fields are rejected by the validator.
- `web/static/course/` is generated by `course_builder build` and is not committed.

## Running locally

`./scripts/dev/serve.sh` needs only this machine. Audio is synthesized locally by Kokoro (ONNX Runtime and eSpeak NG, model files downloaded once into `models/`) or by the macOS voices (`--engine macos-say`); both are encoded with `ffmpeg`. Changing the engine or a voice changes the clip file names, and the build removes the clips no longer referenced.
